I would like to create a desktop application using react, tauri, nodejs, typescript. I'll let you choose how the data is stored.  I was thinking either SQLite or a JSON file.  Have a data access layer so it will be easy to swap out  it will have 2 panes.  On the left will be a tree of note names. You can add new note names, remove them, and indent them.  If you click on a parent note name, it will colapse its children.  If you click it again it will expand.
On the right pane will be the notes.  So if you click on a note in the left pane, the note will display in the right.  The notes will store their data in markdown.  The markdown will be WYSIWYG, so for example typing  "# foo" will automatically diplay "foo" as a header, and **bold** will display as bold.  Ideally, the formatting symbols will not display - just like typora works.  Though if it works like markdown fles do in Visual Studio Code that would probably be OK.  I don't particularly care how sophisticated the markdown support is - just the basic formatting is fine.  Ideally use an open source component for this - no need to write the markdown code yourself.
Some notes can be set to encrypted.  If a note is encrypted, you can't view or edit it unless you enter a password.  All encrypted notes will have the same password, so you only have to enter it once.  In addition, there should be a function to lock the notes, and it should auto-lock after 15 minutes of the app being idle.
In addition to markdown notes, some of the notes can be to do lists.  They should be stored in markdown format as well.  The lists can have multiple items, with 4 possible priorities: high, medium, low and none.  Each item in the list can have 0 or more notes associated with them.  To do lists can be sorted by priority/alphabetical or unsorted.  It should be easy to toggle between the two.  If unsorted, you should be able to easily change the sort by dragging.  Ideally they would work and look basically like the app todoist.
